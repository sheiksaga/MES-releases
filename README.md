# MES Releases

This repository holds release artifacts for [MES (My Everything Search)](https://github.com/sheiksaga/MES) — a fast Windows launcher.

It contains only signed installer builds, their signatures, and the auto-updater manifest (`latest.json`). It is **not** the app's source code (that repository is private) and is not the primary distribution channel — get MES from its Gumroad page.

This repo exists solely so MES's built-in auto-updater has a public location to check for and download new versions.
