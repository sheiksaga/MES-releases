# MES Releases

This repository holds release artifacts for [MES](https://ds-hem.pages.dev/blog/mes/) — a fast Windows launcher.
It contains only installer builds, and the auto-updater manifest (`latest.json`). 
This repo exists solely so MES's built-in auto-updater has a public location to check for and download new versions.
